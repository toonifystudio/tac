# Tenant Application Check (TAC)

Initial repository for the Tenant Application Check (TAC) system. This project implements a desktop application that ingests rental applications from Gmail, verifies required documents, performs OCR, creates PDF packages, and supports a review/approval workflow.

This repository will be developed on feature branches. The `feat/mvp` branch will contain the work for the MVP.

See docs in ARCHITECTURE.md and ROADMAP.md (to be added).
